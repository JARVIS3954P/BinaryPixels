This is a Google Photos Clone, which can be used to store images and play around with them using AI edits.

## Functionalities:
0. Create user account/ log-in to user account.
1. Upload single/multiple photos.
2. Add them to libraries/albums.
3. Archive the images.
4. Add AI modifications to an image.
5. Delete images.
6. Restore or Delete forever from Trash Folder.
7. Change from Dark/Light theme.
