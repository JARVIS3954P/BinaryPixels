# BinaryPixels
Google Photos-inspired image management platform with AI-powered image editing.

## Features
- User authentication
- Photo upload
- Albums/Libraries
- Archive
- Trash and restoration
- Permanent deletion
- AI image modifications
- Dark/Light theme

## Tech Stack
### Backend
- Java
- Spring Boot
- Spring Security
- PostgreSQL
- JWT

### Frontend
- React/Next.js
- TypeScript
- Tailwind CSS
